What this checks

Every serial is decomposed once here into format version, production date, shift and sequence, and stored as real columns. Nothing downstream parses the string again.

The format is chosen per serial, not per file, because June v1 stock ships alongside August v2. Where a serial reads validly as both, the box pack date breaks the tie; if it cannot, the file is held rather than guessed at.

Challan numbers store as year and sequence integers plus an optional suffix. 742 and 742 (A) are two real documents that both reached a customer, so both load.
