{# ================= EN-ICON splash ================= Shown between sign-in and the first screen - the one moment in this app where somebody is genuinely waiting on work (enterApp -> applyBoot -> addScreens -> a fetch per injected screen), and the screen underneath is half-built. Not shown before sign-in: the login card renders instantly, so a splash there would be delay with nothing behind it. Every rule below is scoped under #enIconSplash. The artwork's own stylesheet used bare class names, and one of them (.tg) already exists in icon_trace.html - unscoped, this would have reached into v4's page. Speed is one variable, --t. 1 = 3.20s, .6 = 1.92s (used here - Mukesh: sign-in does not happen repeatedly, 2s is acceptable). The mark finishes at 1850ms*t but the wordmark and tagline run to 3200ms*t, so the minimum show is the FULL intro: cutting at the mark leaves the letters half drawn. API: window.EnIconSplash.show() / .hide(); fires "enicon:splashhidden". ================================================= #}
